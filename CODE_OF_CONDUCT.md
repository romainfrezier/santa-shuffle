# Community code of conduct

Treat contributors and users with respect. Welcome different levels of experience, discuss technical trade-offs constructively, and accept corrections. Keep feedback specific to the work.

Harassment, discrimination, threats, sexualized conduct, personal attacks, deliberate disruption, and publishing private information without consent are not acceptable. These expectations apply in issues, pull requests, discussions and other official project spaces.

Maintainers may edit or remove content, limit participation, or ban participants when necessary to protect the community. Responses should be proportionate to the behavior and its impact; good-faith disagreement is welcome.

Report concerns privately to a repository maintainer through a contact they publish. Avoid posting private details publicly. If no private contact is available, ask for one without describing the incident in public. Maintainers must publish a monitored contact before opening public community spaces. If the concern involves a maintainer, contact another maintainer when available. This project currently makes no promise of an independent moderation team.
