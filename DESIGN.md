# Santa Shuffle design
The user pinned Infomaniak Ticketing as the reference. This takes precedence over alternative concepts. Build directly from that reference and the agreed envelope reveal.

Warm raspberry hero (#b62948) with a restrained pink light at its bottom; warm-white paper surfaces; dark plum text. Manrope, self-hosted, 400–800. Large, centered landing title and a single cream action. An envelope is a geometric UI object, not a decorative illustration. Quiet forms and lists share the same type, palette and spacing. Desktop landing is Persuade; event forms are Operate; recipient reveal is Experience.

No fabricated statistics or testimonials, no icon-card grid, no dashboard chrome. One reveal animation, disabled under reduced motion. Real labels, visible focus, readable errors, 44px touch controls. Stack at 700px. Mobile first.
