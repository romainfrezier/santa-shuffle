# Santa Shuffle design

The initial reference is Infomaniak Ticketing. On 2026-11-03 the user requested a substantially warmer identity, richer components and animations.

Cream paper (#faf5eb), cherry red (#b83242), pine green (#255447), blush stationery. Self-hosted Fraunces display headings and Manrope body text. Asymmetric landing with a stack of personalized cards, wax seal and an explicitly labeled shuffle demo. Shared paper surfaces, generous type, pill actions and warm fields extend to management and participant screens.

GSAP handles scoped, finite card animations; canvas-confetti celebrates a user-triggered reveal. Reduced motion disables both. Radix Select provides accessible currency selection; Lucide supplies icons; Sonner displays server feedback. No fake statistics, testimonials, perpetual motion or third-party font requests. Real labels, visible focus, readable errors and 44px controls. Stack at 700px.
